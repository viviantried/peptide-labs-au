# Australian postcode lookup data

`au-postcodes.json` contains Australian postcode, suburb and state pairs derived from the GeoNames `AU.zip` postal code download on 18 September 2026. Coordinates and other fields were removed; duplicate pairs were combined. The checkout downloads this file from the same website and performs lookup in the browser.

Source: https://download.geonames.org/export/zip/AU.zip

GeoNames postal code data is licensed under Creative Commons Attribution 4.0: https://creativecommons.org/licenses/by/4.0/

GeoNames supplies the data as-is. The checkout keeps manual entry available, and customers should verify their delivery address.
